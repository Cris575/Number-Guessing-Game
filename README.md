# Number Guessing Game

A simple console-based number guessing game built with C# and .NET 8.

Project roadmap: [Number Guessing Game](https://roadmap.sh/projects/number-guessing-game)

## Requirements

- .NET 8 SDK or later
- Visual Studio 2022 or later, or any IDE that supports .NET 8

## Running the project

### Using the terminal

1. Open PowerShell or a terminal.
2. Navigate to the project directory:
   - `cd path\to\your\project` (replace with your actual project path)
3. Run the project:
   - `dotnet run`

### Using Visual Studio

1. Open `Number_Guessing_Game.sln` in Visual Studio.
2. Set `Number_Guessing_Game` as the startup project if necessary.
3. Press `Ctrl+F5` to run without debugging, or press `F5` to run with debugging.

## How to play

1. Select a difficulty level:
   - Easy: 10 chances
   - Medium: 5 chances
   - Hard: 3 chances
2. Enter a number between 1 and 100 when prompted.
3. Use the hints to determine whether the secret number is higher or lower.
4. Guess the number before running out of chances.
